# **Stack Project Description**

## **Technical & Project Requirements**

Django and Angular Stack Project:  
**Using Github**  
**A branch for each feature**  
**Documentation**

* A README file explaining how to set up and run the project.

**Presentation**

* A presentation demonstrating the project features and discussing the technologies used.  
* A demo of the application with a walkthrough of the codebase.

## **1\. User Management**

* User registration & login (Email, Phone, Social Media(using google... bonus)) (confirmation Email)  
* Profile management (name, address, payment details, etc.) (BOUNS)
* Multi-user roles (Customer, Seller(BOUNS), Admin) 
* Wishlist & Favorites  (BOUNS)
* Order history  (BOUNS)
* Reviews & Ratings

## **2\. Product Management**

* Categories  (BOUNS)
* Product listings with images, descriptions, and prices  
* Stock availability  
* Search by name and Filtration by (price, Category,...)

## **3\. Shopping Cart & Checkout**

* Add/remove items from cart  
* Quantity adjustment  
* Order summary with price breakdown  
* Guest checkout option  
* Multiple payment methods (Credit card or PayPal, Cash on Delivery, Wallet)  
* Apply promo codes and discounts (bonus)

## **4\. Order Management (BOUNS)**

* Order placement & confirmation  
* Order tracking with status updates  
* Order notifications via email

## **5\. Payment Integration**

* Secure payment gateway (Stripe, PayPal, Razorpay, etc.)  
* Card saving & auto-fill for quick checkout (bonus)

## **6\. Admin Panel Features**

* User management (approve/restrict users) // soft delete  
* Product & category management  
* Order & shipping management  (BOUNS)
* Discounts & promo code management (bonus)  
* Content management for banners & homepage(BOUNS)

## **7\. Seller (Vendor) Management (BOUNS)**

* Seller registration & profile setup  
* Product listing & inventory management  
* Order processing & status updates (bonus)  
* Earnings & payout management (bonus)

## **Bonus: Marketing & Engagement**

* Push notifications for promotions & updates  
* Email marketing & newsletters  
* Loyalty programs & reward points  
* Social media sharing & referral bonuses  
* Discounts, promotions, and coupons  
* Multi-language
