# Code of Conduct

This project adopts the Contributor Covenant Code of Conduct, version 3.0:

https://www.contributor-covenant.org/version/3/0/code_of_conduct/

## Project Expectations

- Be respectful, direct, and professional.
- Discuss technical decisions with evidence from the codebase, docs, tests, or requirements.
- Keep reviews focused on correctness, maintainability, security, accessibility, and user impact.
- Ask for clarification when requirements are ambiguous.
- Share context early when a change affects shared files, API contracts, or another developer's work.

## Reporting

Report possible code of conduct violations privately to the project maintainers or team lead. Include the relevant links, screenshots, timestamps, and participants when available.

Maintainers should handle reports confidentially, evaluate them promptly, and respond with proportionate action.

## Scope

This code of conduct applies to repository work, issues, pull requests, documentation, planning discussions, and project communication.
